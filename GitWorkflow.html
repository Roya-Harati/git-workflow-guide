📋 مراحل به ترتیب

۱

ساخت مخزن 👑 Lead

Lead یه مخزن جدید توی گیت‌هاب می‌سازه و Collaborators رو اضافه می‌کنه.

📍 کجا: GitHub.com → New Repository → Settings → Collaborators

git init
۲

Clone 👨‍💻 Developers

اعضای تیم پروژه رو روی کامپیوتر خودشون کپی می‌کنن.

📍 کجا: GitHub Desktop → File → Clone Repository

git clone https://github.com/USERNAME/REPO.git
⚠️ نکته: Clone فقط یه بار در ابتدا انجام می‌شه. بعد از اون از Pull استفاده کن.
۳

ساخت Branch 👥 همه

هر نفر یه شاخه جدید برای فیچر خودش می‌سازه تا main خراب نشه.

📍 کجا: GitHub Desktop → Current Branch → New Branch

git checkout -b feature-login
۴

Commit + Push 👥 همه

تغییرات رو ذخیره و به گیت‌هاب می‌فرستن.

📍 کجا: GitHub Desktop → Commit → Push

git add .
git commit -m "feat: add login page"
git push -u origin feature-login
۵

Pull Request 👥 همه

درخواست ادغام شاخه‌شون با main رو می‌فرستن.

📍 کجا: GitHub.com → مخزن → Compare & pull request

۶

Merge 👑 Lead

Lead کدها رو بررسی می‌کنه و PR رو Merge می‌کنه.

📍 کجا: GitHub.com → PR → Merge pull request

۷

Pull 👥 همه

همه آخرین تغییرات main رو می‌گیرن تا برای فیچر بعدی آماده باشن.

📍 کجا: GitHub Desktop → Current Branch → main → Pull origin

git checkout main
git pull origin main

💥 Conflict چیه؟

وقتی دو نفر یه خط از یه فایل رو متفاوت تغییر بدن، Git نمی‌دونه کدوم رو انتخاب کنه!

⚠️ علامت‌های Conflict توی فایل:

<<<<<<< HEAD
background: blue; ← کد فعلی main
=======
background: red; ← کد تو
>>>>>>> feature-products
✅ راه‌حل:
  1. فایل رو باز کن
  2. تصمیم بگیر کدوم کد رو نگه داری
  3. خطوط <<<، ===، >>> رو پاک کن
  4. Commit و Push کن

⭐ قوانین طلایی

۱. قبل از شروع کار، همیشه Pull کن
git checkout main && git pull origin main
۲. روی main مستقیم کار نکن — همیشه Branch بساز
git checkout -b feature-xyz
۳. پیام‌های Commit واضح بنویس

❌ update
✅ feat: add login validation
✅ fix: navbar dropdown bug

۴. PR کوچیک بفرست، نه بزرگ

PR ۱۰۰ خطی راحت بررسی می‌شه، ۱۰۰۰ خطی نه!

۵. همیشه Branch خودت رو از main آپدیت نگه دار
git pull origin main

🎯 خلاصه یه خطی

یه نفر مخزن رو می‌سازه → بقیه Clone می‌کنن →
هر کس Branch خودش رو می‌سازه → Commit + Push →
PR می‌فرسته → Lead Merge می‌کنه →
همه Pull می‌کنن → برگرد به مرحله Branch
